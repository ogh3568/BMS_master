# 추가 기능 제안

평가 기준
- **가치**: 엔지니어 시간 절감, 품질·안전 개선 정도 (상/중/하)
- **공수**: 기존 모듈 재사용 정도를 고려한 추가 작업량 (소: ≤1주, 중: 2~3주, 대: ≥4주)
- **기반**: 이미 계획된 모듈 중 무엇을 재사용하는가

## 1. 강력 추천 (적은 공수로 큰 가치)

| ID | 기능 | 설명 | 가치 | 공수 | 기반 |
|---|---|---|---|---|---|
| F1 | **FW 버전 간 동작 비교 (Behavior Diff)** | 같은 로그 세트를 두 FW/파라미터 버전으로 SIL 재생해 SOC·보호 동작·상태 천이 차이를 자동 리포트. 릴리스 전 회귀 검출 | 상 | 소 | M6 `sil.compare` |
| F2 | **파라미터 What-if 미리보기** | GUI에서 파라미터 슬라이더를 움직이면 선택한 로그 구간의 SIL 결과가 즉시 바뀜. 캘리브레이션 엔지니어의 시행착오를 줄임 | 상 | 중 | M6, M9 |
| F3 | **필드 로그 자동 분류(Triage)와 유사 사례 검색** | 대량 로그를 지표 특징으로 클러스터링하고, 과거 위키 `findings/`에서 비슷한 사례와 해결책을 찾아줌 | 상 | 중 | M2, M4 |
| F4 | **자연어 로그 질의** | "지난주 충전 중 셀 편차 30 mV 넘은 구간 보여줘" → 조건식으로 변환 → `log.query` 실행 → 그래프 | 상 | 소 | M2, M8 |
| F5 | **캘리브레이션 데이터 검증·diff** | A2L/캘리브레이션 세트 간 차이, 범위 위반, 단위·Q-format 불일치, 테이블 단조성 위반 자동 점검 | 상 | 소 | M1 |
| F6 | **신규 셀 온보딩 마법사** | 새 셀의 OCV·HPPC·GITT 실험 데이터 → ECM 파라미터 자동 추출 → 물리 모델 초기값 → 최적화까지 한 흐름으로. 셀 파라미터 라이브러리에 등록 | 상 | 중 | M5, M11 |
| F7 | **테스트 시나리오 자동 생성** | 코드의 분기·임계값을 보고 경계값과 고장 주입 시나리오를 생성해 SIL로 실행. 보호 로직 커버리지 리포트 | 상 | 중 | M1, M6, M11 |

## 2. 추천 (중간 공수, 전략적 가치)

| ID | 기능 | 설명 | 가치 | 공수 | 기반 |
|---|---|---|---|---|---|
| F8 | **SOC/SOH 불확도 정량화 대시보드** | 추정값과 신뢰 구간, 불확도가 커지는 조건(저온, LFP 평탄 구간, 장시간 무휴지) 표시 | 중 | 중 | M2, M7 |
| F9 | **급속충전 프로파일 최적화** | 만충 시간과 리튬 플레이팅 위험(음극 전위 < 0 V 근사)의 트레이드오프를 BO로 최적화 | 상 | 대 | M5, M7 |
| F10 | **보호 임계값·알람 피로 분석** | 보호 플래그의 오탐/정탐 구분, 임계값 마진 최적화 제안 | 중 | 소 | M2 |
| F11 | **EU 배터리 규정 대응 SOH 리포트** | 규정(2023/1542)이 2027-02부터 EV 배터리 여권에 SOH 등 BMS 기반 정보를 요구한다는 보고가 있음. SOH 산출 근거·추적성 리포트 템플릿 | 중 | 중 | M3, M7 |
| F12 | **FMEA·진단 커버리지 보조** | 코드의 고장 감지 로직과 고장 주입 결과를 연결해 FMEA 표 초안과 진단 커버리지 계산 | 중 | 중 | M1, M11 |
| F13 | **요구사항 ↔ 코드 ↔ 테스트 추적** | 요구 문서(엑셀/워드 export)와 코드 함수·테스트를 연결하는 위키 관계. 감사 대응 | 중 | 중 | M1, M4 |
| F14 | **열 폭주 전조 감지 연구 트랙** | dT/dt, 셀 전압 급락, 온도 센서 간 상관 이상, (가스 센서가 있으면) 융합 | 상 | 대 | M2, M7, M11 |
| F15 | **코드 리뷰 봇 (pre-commit/CI)** | 고정소수점 위험 패턴, 매직 넘버, 파라미터 범위 주석 누락을 PR마다 자동 코멘트. MISRA 대체가 아니라 보조 | 중 | 소 | M1 |

## 4. 권장 순서

1. **P1~P3에 포함** (공수 소, 기존 모듈에서 거의 바로 나옴): F1, F4, F5, F10, F15
2. **P4~P5에 포함**: F2, F3, F6, F7
3. **v1.1 이후**: F8, F9, F11, F12, F13, F20
4. **연구 트랙**: F14, F16, F18, F19
5. **선택**: F17

F1(FW 비교)과 F5(캘리브레이션 검증)는 거의 추가 비용 없이 바로 쓸 수 있다. MS1~MS3 시연에 넣으면 이해관계자 설득에 효과적이다.
