# SPM 모델 정확도 향상 트랙

## 1. 배경 (2026-10-15 확인)

- 사내 모델은 **SPM(Single Particle Model)**이다.
- FW용 저전력 모델은 **연구 단계**다. 지금은 FW로 개발하지 않고 **모델 자체의 정확도를 높이는 중**이다.
- 따라서 이 플러그인의 첫 번째 가치는 "SPM 정확도를 얼마나, 어디서, 왜 올릴 수 있는가"에 답하는 것이다. FW 이식(고정소수점, Android)은 뒤로 미룬다(ADR-019).

## 2. 정확도 평가 체계 (먼저 고정해야 할 것)

정확도를 높이려면 "무엇으로 재는지"부터 고정해야 한다. 그래야 파라미터 변경, 모델 확장, 버전 간 비교가 같은 잣대로 된다.

| 항목 | 내용 |
|---|---|
| 벤치마크 로그 세트 | SBL 로그를 용도별로 묶은 고정 세트. **학습용 / 검증용 / 시험용**을 분리하고 시험용은 최종 비교에만 쓴다 |
| 세트 구성 (권장) | 펄스·이완(HPPC류), 완전 충방전(끝단), 정전류 여러 C-rate, 여러 온도, 주행·필드 프로파일, 노화 단계별 |
| 지표 | 전압 RMSE·최대 오차(전체, **운전 영역별**: 순간 응답, 동특성, 이완, 고율, SOC 끝단, 저온), 이완 꼬리 오차, (참값이 있으면) SOC 오차, 온도 오차 |
| 표기 | 모든 결과는 "모델 버전 + 파라미터 세트 + 벤치마크 세트 버전"과 함께 기록 (run.json) |
| 산출물 | **정확도 대시보드**: 영역별 오차 히트맵(영역 × 로그), 버전 간 비교, 개선 추이 |

## 3. 파라미터 오차와 모델 구조 오차 분리 (핵심)

SPM은 전해질 내 농도·전위 분포를 무시하는 단순화 모델이다. 그래서 고율·저온에서는 **파라미터를 아무리 맞춰도 줄지 않는 오차(구조 오차)**가 남는다.
이를 구분하지 않으면 최적화가 다른 파라미터를 비물리적으로 비틀어 구조 오차를 흡수한다. 그 결과 학습 로그에서는 좋아 보이고 다른 조건에서는 나빠진다.

**분리 절차**
1. [09 파이프라인](/plan/09_param_inference.md)으로 파라미터를 최적화한다.
2. 남은 잔차를 운전 영역 특징(|I|, dI/dt, SOC, T, 이완 경과 시간, 누적 Ah)으로 회귀한다(가벼운 회귀 또는 GP).
   - 잔차가 특징으로 **체계적으로 설명되면** 구조 오차 후보
   - 설명되지 않는 잡음 수준이면 측정 잡음
3. **파라미터 비틀림 검사**
   - 최적값이 사전분포 경계에 붙었는가
   - 온도·C-rate별로 따로 맞췄을 때 같은 파라미터 값이 크게 달라지는가
   - 그렇다면 그 파라미터가 구조 오차를 흡수하고 있다는 신호다
4. 결과 리포트: **"전체 잔차 중 파라미터로 줄일 수 있는 부분 X%, 구조 오차 Y%, 잡음 Z%"**와 영역별 내역.

## 4. SPM 구조 확장 후보 (AI가 근거와 함께 제안)

구조 오차가 확인된 영역에 맞춰 확장 후보를 고르고, 예상 이득과 연산 비용을 함께 제시한다.

| 확장 | 해결하는 잔차 서명 | 추가 파라미터 | 연산 비용 증가 |
|---|---|---|---|
| 전해질 전위·농도 보정 (SPMe류) | 고율에서 전류에 비례해 커지는 오차, 고율 이완 초기 | 전해질 확산계수·전도도, 전달수, 두께·공극률(묶음) | 중 |
| 집중(lumped) 열 결합 | 온도 변화 구간 오차, 자체 발열로 인한 드리프트 | 열용량, 열전달 계수, (엔트로피 계수) | 소 |
| 농도 의존 확산계수 D_s(x) | 특정 SOC 구간에서만 이완 오차 | 저차 기저 계수 2~4개 | 소 |
| OCV 히스테리시스 | 같은 SOC에서 충전/방전 반대 부호 오차 (특히 LFP·실리콘 음극) | 히스테리시스 크기·속도 | 소 |
| SEI·피막 저항, 이중층 용량 | 펄스 직후 수 ms~s 응답 오차 | R_film, C_dl | 소 |
| 입자 크기 분포 (다중 입자) | 고율 끝단의 완만한 전압 강하 모양 | 분포 폭 | 중~대 |
| 노화 상태 변수 (LLI, LAM) | 노화 단계 로그 간 체계적 차이 | 손실률 파라미터 | 소 |
| 잔차 보정 데이터 모델 (하이브리드) | 물리 확장으로 안 잡히는 나머지 | 작은 회귀·NN | 소~중 (해석성 낮음, 마지막 수단) |

**절차**: 후보 확장을 C 모델이나 Python 기준 모델에 구현 → 같은 벤치마크로 비교 → 영역별 개선과 연산량 증가를 함께 보고 → 사람이 채택 결정 → 위키 `algorithms/spm/`에 기록.

**AI의 역할**
- 잔차 서명을 보고 확장 후보를 고르고 이유를 쓴다.
- 확장 코드 초안을 만든다.
- 결과를 해석한다.

모든 채택 판단은 벤치마크 수치를 근거로 한다.

## 5. 정확도-연산량 파레토 (FW 저전력 모델 연구 지원)

FW 저전력 모델은 연구 단계다. 그래서 지금 할 일은 FW 이식이 아니라 **"얼마나 단순하게 만들면 정확도를 얼마나 잃는가"를 체계적으로 측정하는 도구**다.

| 축소 수단 | 예 |
|---|---|
| 입자 내부 격자 수 | 확산 방정식 이산화 점 수 (예: 20 → 10 → 5) |
| 근사 해법 | 다항식 근사(2차·3차 프로파일 근사), 확산 전달함수 근사 |
| 갱신 주기 | 1 s → 10 s, 휴지 중 이벤트 기반 갱신 |
| 테이블 해상도 | OCP·저항 테이블 점 수 |
| 수치 정밀도 | float64 → float32 → (향후) 고정소수점 |
| 구조 단순화 | SPM → 등가회로 하이브리드 |

- 각 축소 설정마다 벤치마크 정확도(영역별)와 연산량(연산 횟수, 실행 시간, 메모리)을 측정해 **파레토 곡선**을 그린다.
- 결과는 FW 저전력 모델 연구의 설계 근거가 된다. "이 정확도 예산이면 이 구성"을 고르는 데 쓴다.
- 실제 FW 포팅(고정소수점, MCU 빌드)은 연구 결론이 난 뒤 M6 계획대로 진행한다.

## 6. 일정 반영

| 주차 | 작업 |
|---|---|
| 1–8 (P0–P1) | SBL 변환, 벤치마크 세트 v1 구성, 정확도 지표·대시보드, SPM x86 SIL 빌드(7–8주) |

| 이후 | 채택된 확장 반영, 저전력 연구 결론에 따라 FW 포팅 착수 |

## 7. 이 트랙의 수용 기준 (초안)

- 벤치마크 세트와 지표를 고정하고 버전 관리함
- 시험 세트 기준 전압 RMSE가 현재 모델보다 개선됨 (목표치는 현재 수준을 측정한 뒤 정함)
- 잔차의 파라미터/구조/잡음 분해 리포트를 자동 생성함
- 확장 후보마다 영역별 이득과 연산 비용을 비교한 리포트가 있음
- 축소 설정 5개 이상의 파레토 곡선
