## 4. 완료 정의(DoD)

모든 작업은 다음을 만족해야 완료다.
1. 단위 테스트, 타입 검사, lint 통과
2. 결과물이 있으면 실행 기록(run.json)을 남김
3. 관련 위키 페이지를 갱신하거나 생성함
4. 새 의존성이 라이선스 게이트를 통과함
5. 사용자 영향이 있으면 GUI 또는 CLI 도움말을 갱신함
6. AI 기능이면 평가셋 점수가 떨어지지 않음

## 5. 일정 위험 버퍼

- 각 단계 끝에 1주씩 버퍼를 두었다. 데이터 제공이 2주 이상 늦어지면 P2와 P3의 순서를 바꾼다.
- 스웰링은 데이터에 따라 v1.1로 미룰 수 있다.
