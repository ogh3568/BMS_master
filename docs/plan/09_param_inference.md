# 최적화 대상 파라미터 추론·예측 설계

## 1. 문제 정의

| 항목 | 내용 |
|---|---|
| 주어진 것 | BMS C 소스와 **SPM(Single Particle Model, 확인)**, 시계열 로그(엑셀·txt → SBL), 기존에 최적화한 34개 + diffusivity 목록 |
| 34개 목록의 역할 | **입력이 아니라 최소 힌트이자 평가 기준.** AI는 이 목록 없이도 후보를 찾아야 하고, 이 목록은 "AI의 추론이 맞는지" 확인하는 블라인드 테스트에 쓴다 |
| 목표 | ① 수백 개 파라미터 중 **지금 이 데이터에서 최적화하면 효과가 있는 부분집합**을 고른다 ② 최적화 전에 **예상 개선량을 예측**한다 ③ 최적화 후 예측과 실제를 비교해 다음 추론을 개선한다 |
| 시뮬레이터 | **사내 C 모델 자체**를 x86 공유 라이브러리로 빌드해 SIL로 실행한다(ADR-015). PyBaMM은 교차 확인용 선택 사항 |

### SPM에서 흔히 나오는 파라미터 묶음 (탐색 사전 지식)

> SPM은 전해질 효과를 무시하므로, 고율·저온에서 남는 오차는 파라미터가 아니라 **모델 구조** 문제일 수 있다. 최적화 뒤 잔차를 파라미터/구조/잡음으로 분해하는 절차는 [모델 정확도 트랙](/plan/10_model_accuracy_track.md) §3에 있다.

| 묶음 | 예 | 로그에서 드러나는 곳 |
|---|---|---|
| 용량·화학양론 창 | 전극 용량, 0%/100% SOC에서의 화학양론 x0/x100·y0/y100 | 완전 충방전 끝단 전압, 장시간 쿨롱 누적 |
| 개방전위(OCP) 테이블 | 양·음극 OCP(x) 표, (LFP면) 히스테리시스 | 휴지 후 전압, 충전/방전 같은 SOC에서 차이 |
| 고체 확산 | 양·음극 확산계수 D_s(+ 온도·SOC 의존), 입자 반경 R_p → 실질적으로는 시간상수 R_p²/D_s | 펄스 후 이완 꼬리, 고율 구간 끝단 |
| 반응 속도 | 교환전류밀도 i0 또는 속도상수 k, 전하전달 계수 | 펄스 시작 직후 수 초, 저온 |
| 저항 | 옴 저항 R0, 접촉·SEI 저항, (SPMe면) 전해질 관련 항 | 전류 계단 순간 전압 점프 |
| 온도 의존 | 활성화 에너지(Arrhenius) E_a(D_s, k, R0) | 같은 프로파일의 온도별 오차 차이 |
| 열 모델 | 열용량, 열전달 계수 | 온도 상승·하강 기울기 |
| 노화 | 용량 손실률, 저항 증가율, 리튬 손실 | 장기간 드리프트 |
| 추정기 캘리브레이션 | 칼만 필터 Q/R, 보정 게인, 휴지 판정 시간 | 모델 출력이 아니라 SOC 출력 오차 |
| 함수형 파라미터 | 위 항목 중 테이블(OCP, D_s(x), R0(SOC,T)) | 테이블 칸 하나하나가 "파라미터"가 되어 수가 수백 개로 늘어나는 주원인 |

## 2. 파이프라인

```
[A] 코드에서 후보 발견 ──► [B] 물리 의미·사전분포 부여 ──► [C] 현재값으로 SIL 재생, 잔차 계산
                                                                 │
          ┌──────────────────────────────────────────────────────┘
          ▼
[D] 잔차를 운전 영역별로 분해(서명) ──► [E] 영역별 민감도 → 잔차 귀속, 개선량 예측
          │                                         │
          ▼                                         ▼
[F] LLM 가설(서명 ↔ 물리 지식) ◄──────► [G] 식별성 검사 + 부분집합 선택 (예산 내 최대 예상 개선)
                                                    │
                                                    ▼
                         [H] BO/국소 최적화 (warm start) ──► [I] 예측 vs 실제 비교, 위키 축적
                                                    │                  │
                                                    └──── 잔차 재진단 ◄─┘ (활성 집합 갱신, 반복)
```

### [A] 코드에서 후보 발견 (M1 재사용)
- 모델 소스에서 `const`·전역 구조체·`#define`·테이블을 추출하고, 모델 방정식이 쓰는 위치를 데이터 흐름으로 묶는다. 예: `Ds_neg`가 확산 방정식 갱신식에 쓰인다.
- 산출물: 파라미터 레지스트리(`kind: physical | model | calibration`, 원래 값, 타입, Q-format, 사용 함수).
- 테이블은 **함수형 파라미터**로 따로 표시한다(차원, 축).

### [B] 물리 의미와 사전분포 부여
- 변수명, 주석, 수식 내 역할(예: `exp(-Ea/R*(1/T-1/Tref))` 안에 있으면 활성화 에너지)로 묶음을 분류한다. 규칙을 먼저 쓰고, LLM은 규칙으로 못 정한 것만 판단한다.
- 사전분포: 화학별 문헌 범위(위키 `cells/`, `algorithms/`)와 현재값 기준 배율(예: ×0.3~×3, 로그 스케일).
- **차원 축소용 재파라미터화**
  - 테이블 → 저차원 기저. 현재 테이블 × (1 + 저차 스플라인 보정 3~5개 매듭) 또는 OCP 이동·신축(shift/stretch) 2~3개
  - 확산계수 → 시간상수 τ = R_p²/D_s (R_p와 D_s를 동시에 식별할 수 없기 때문)
  - 온도 의존 → 기준 온도 값과 E_a 2개

### [C] SIL 재생과 잔차
- SBL L3 로그(`model.*`가 있으면 내부 상태까지 비교)를 사내 C 모델로 재생한다.
- 잔차 r(t) = 측정 전압 − 모델 전압. 셀별 또는 팩 평균. SOC 출력이 있으면 `ref`나 대체 기준 대비 SOC 잔차도 계산한다.

### [D] 잔차 서명 (운전 영역 분해)
로그를 운전 영역으로 나누고, 영역별 잔차 통계(평균, RMSE, 추세)를 **서명 벡터**로 만든다.

| 영역 | 정의(초안) |
|---|---|
| 순간 응답 | 전류 계단 후 0~2 s |
| 단기 동특성 | 계단 후 2~60 s |
| 이완 | 전류≈0, 계단 후 1~60 min |
| 고율 | \|I\| > 1C |
| SOC 끝단 | SOC < 15% 또는 > 85% |
| 중간 SOC | 15~85% |
| 저온 / 상온 / 고온 | T < 10 / 10~35 / > 35 °C |
| 충전 vs 방전 | 부호별 |
| 장기 추세 | 시간·누적 Ah 대비 잔차 기울기 |

### [E] 잔차 귀속과 개선량 예측 (결정론적, 핵심 계산)
1. 각 후보 파라미터(또는 묶음)를 조금씩 바꿔 SIL을 다시 돌려 **영역별 민감도 행렬 J**(잔차 변화 / 로그 스케일 파라미터 변화)를 구한다. 경량 C 모델이라 수백 번 재생도 빠를 것으로 본다(가정, P0에서 측정).
2. 선형화 최소제곱으로 **예상 개선량**을 계산한다.
   - 부분집합 S에 대해 Δθ_S = argmin ‖r − J_S Δθ_S‖² + λ‖Δθ_S/σ_prior‖² (사전분포로 정규화)
   - 예상 잔차 = ‖r − J_S Δθ_S‖ → **"이 k개를 최적화하면 RMSE가 X mV에서 약 Y mV로"**
   - 비선형성이 커서 선형 예측이 틀릴 수 있으므로 [I]에서 보정한다.
3. 전역 민감도(Morris, 저비용)로 국소 선형화가 놓치는 파라미터를 보완한다.

### [F] LLM 가설 (해석과 교차 확인)
LLM은 서명과 [E] 결과를 보고 물리적으로 말이 되는지 판단한다. 위키 `algorithms/param_inference/signatures.md`에 쌓을 **서명 ↔ 원인 지식표(초안)**:

| 잔차 서명 | 우선 의심 | 함께 확인할 것 |
|---|---|---|
| 전류 계단 순간 점프 오차 | R0, 접촉 저항 | 온도 의존이면 R0의 E_a |
| 펄스 시작 수 초 오차, 저온에서 커짐 | 교환전류밀도·속도상수, 그 E_a | R0와 상관 |
| 이완 꼬리 모양 오차 | 확산 시간상수(음극/양극) | 고율 끝단 오차도 같이 있으면 확신 상승 |
| SOC 끝단에서만 오차 | 화학양론 창, OCP 테이블 끝단, 용량 | 장시간 쿨롱 누적 오차 |
| 충전/방전 같은 SOC에서 반대 부호 오차 | OCP 히스테리시스(LFP), 과전위 비대칭 | 화학이 LFP인지 |
| 온도 구간별로 오차 크기만 다름 | 활성화 에너지 묶음 | 열 모델 온도 오차 |
| 시간에 따라 단조 증가하는 SOC 오차 | 용량·노화 항, **전류 센서 오프셋** | 오프셋이면 모델 파라미터가 아니라 데이터 문제로 분류 |
| 온도 예측 기울기 오차 | 열용량·열전달 계수 | 냉각 조건 메타 |
| 모델 전압은 맞는데 SOC 출력이 틀림 | 추정기 캘리브레이션(Q/R, 보정 게인) | 모델 파라미터 최적화 대상이 아님 |

LLM 규칙
- 가설마다 **반증 조건**을 적는다.
- [E]의 수치와 맞지 않는 가설은 버린다.
- "데이터 문제(센서 오프셋, 시간 정렬 오류)"를 "모델 문제"보다 먼저 확인한다.

### [G] 식별성 검사와 부분집합 선택
- **식별성**
  - 정규화한 J_S의 공선성 지수(collinearity index)
  - 상관이 |ρ|>0.95인 쌍은 하나만 남기거나 재파라미터화
  - 데이터 대비 파라미터 수 상한(유효 자유도)
- **선택 문제**: 예산 k(초기 10~20) 안에서 "예상 개선량 − 식별성 벌점 − 사전분포 이탈 벌점"을 최대화한다. 탐욕적 전진 선택 + 교환 탐색으로 푼다.
- **산출물**: 파라미터 순위표. 행마다 예상 개선량, 근거 영역, 관련 가설, 식별성 점수, 신뢰도가 있다. 사람이 체크박스로 확정한다(GUI ④).

### [H] 최적화
- 선택한 부분집합만 BO(Optuna 기본, BoTorch 선택) 또는 국소 최적화(Levenberg–Marquardt)로 푼다.
- 기존 값과 기존 34개 결과를 시작점으로 쓴다.
- 목적함수: 영역 가중 RMSE + 사전분포 벌점. 학습에 쓰지 않은 로그로 검증한다.

### [I] 예측 검증과 학습
- 예측 개선량과 실제 개선량을 비교해 **예측 정확도**를 기록한다(KPI).
- 실행 결과는 위키 `experiments/`에, 확인된 서명↔원인 사례는 `signatures.md`에 추가한다. 다음 셀·프로젝트에서 사전 확률로 쓴다.
- 잔차를 다시 진단해 효과 없는 파라미터는 빼고 새로 드러난 것은 넣는다(활성 집합 갱신). 목표 RMSE 도달, 개선 정체, 식별성 한계 중 하나면 멈춘다.

## 3. 평가 방법 (34개의 쓰임)

| 시험 | 방법 | 통과 기준(초안) |
|---|---|---|
| **합성 복원 시험** | 사내 C 모델로 참 파라미터 중 일부(예: 5~15개)를 바꿔 합성 로그를 만들고, AI가 바뀐 것을 찾아내는지 본다 | 상위 k개 재현율 ≥80%. 복원값이 참값의 ±10% |
| **블라인드 34 시험** | 34개 목록을 숨긴 채 실측 로그로 순위를 만든다. 상위 50개 안에 34개가 얼마나 들어 있는지와, AI 선택 집합의 검증 RMSE를 본다 | 검증 RMSE가 기존 34개 최적화 결과와 같거나 더 낮음. 겹침률은 참고 지표(겹치지 않아도 RMSE가 낮으면 새 발견) |
| **예측 정확도** | 예상 개선량과 실제 개선량 비교 | 순위 상관(Spearman) ≥0.7, 크기 오차 ±30% |
| **일반화** | 다른 온도·프로파일·노화 단계 로그로 검증 | 학습/검증 RMSE 비율 ≤1.5 |

## 4. 필요한 데이터와 로그 권고

- **SBL L3**(`model.v_pred` 등 내부 출력 포함)가 가장 좋다. L2만 있어도 SIL로 모델 출력을 다시 계산할 수 있다.
- 서로 다른 정보가 담긴 프로파일을 섞는다: 펄스+이완(HPPC류), 완전 충방전(끝단), 여러 온도, 주행·필드.
- 참값(`ref.i`, `ref.ah`)이 있으면 센서 오프셋과 모델 오차를 분리할 수 있다.
